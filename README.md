# Course Tracker 📚
https://cdanielmuller246-hub.github.io/course-tracker/

Un rastreador de progreso de cursos minimalista, liviano y en un **único archivo HTML**. Diseñado para funcionar 100% offline y sin necesidad de servidores ni dependencias externas.

## 🚀 Características

- **Grilla interactiva:** Visualiza las lecciones como casillas numeradas para marcar y desmarcar tu avance rápidamente.
- **Gestión multicurso:** Agrega nuevos cursos especificando su nombre y cantidad total de lecciones.
- **Persistencia local:** Guarda automáticamente tu progreso en el navegador mediante `localStorage`.
- **Importar / Exportar:** Descarga un respaldo de tus datos en JSON para mover tu progreso a otro dispositivo o navegador.
- **Sin instalación:** Funciona abriendo directamente el archivo `.html` en cualquier navegador web.

## 🛠️ Tecnologías

- **HTML5**
- **CSS3** (Grid Layout, Flexbox y Variables CSS)
- **JavaScript Vanilla** (sin frameworks ni librerías)

## 📂 Uso local

1. Clona este repositorio o descarga el archivo `index.html`.
2. Haz doble clic en `index.html` para abrirlo en tu navegador favorito.
3. ¡Comienza a marcar tus lecciones!
